# china-iptv-500

面向 APTV / Apple TV 的中国及海外电视直播订阅。

## 当前版本

### 🇨🇳 中国稳定版

- 最多约 **350 个频道**
- 优先近期自动检测 / 自动筛选源
- 优先 CCTV、卫视、1080p / 720p、低响应线路
- 自动去重并统一频道名称
- 适合日常观看

### 🇨🇳 中国扩展版

- 最多 **500 个中国频道**
- 在稳定源基础上补充更多地方台及冷门频道
- 频道更多，但个别公网源可能因地区、运营商或上游变化暂时不可播

### 🌏 海外稳定版

覆盖以下地区：

- 🇯🇵 日本
- 🇹🇼 台湾
- 🇭🇰 香港
- 🇲🇴 澳门
- 🇰🇷 韩国
- 🇺🇸 美国
- 🇬🇧 英国

海外稳定版会通过 GitHub Actions 自动检测直播地址。

只有当次检测能够正常访问并返回有效 HLS / 视频内容的频道，才会加入稳定版。

优先：

- HTTPS
- HLS / M3U8
- 1080p / 720p
- CDN / 官方直播线路
- 低延迟线路

自动排除：

- Geo-blocked
- Offline
- Broken
- Not 24/7
- 无法连接
- 无有效视频内容的线路

## 自动更新

GitHub Actions **每 6 小时自动更新一次**。

中国频道自动更新播放源。

海外频道每次更新时重新进行可用性检测，以尽量减少失效频道。

## APTV 导入方法

在 APTV 中选择：

**配置 → 订阅配置 → 粘贴订阅 URL → 保存并应用**

日常使用建议直接添加：

**全部稳定版 `all_stable.m3u`**

## 说明

本项目仅聚合公开可访问的播放列表地址，不托管任何视频内容。

公网 IPTV 源可能随上游服务器、地区、运营商、CDN 和版权策略变化。

自动检测和自动更新可以显著降低失效频道比例，但不能保证所有频道在所有网络环境下始终可以播放。
